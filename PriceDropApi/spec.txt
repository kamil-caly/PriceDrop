PriceDrop to aplikacja na Androida, która umożliwia użytkownikom śledzenie cen produktów w sklepach internetowych.

Fontend: React Native
Backend: ASP.NET Core Web API
Baza: PostgreSQL

Aplikacja powinna spełniać następujące wymagania:
- Ma umożliwiać rejestrowanie i logowanie użytkowników.
- Zalogowany użytkownik ma możliwość wywołania endpointu do dodawania produktów do śledzenia.
- Zalogowany użytkownik może odświeżyć formatkę z produktami aby zaciągnąć z api najnowsze ich ceny.
- Podczas dodawania produktów do śledzenia, użytkownik podaje link do produktu w sklepie internetowym 
(aktualnie dostępne sklepy: Morele i XKom).
- Dodane dla zalogowanego użytkownika produkty można usuwać i edytować.
- Na backendzie wystawiona jest funkcja cron z azure, która co 6h wysyła powiadomienie (push notification)
do użytkownika, jeśli cena któregoś z jego produktów spadła. W przyszłości planowane jest dodanie możliwości ustawienia
czasu wysyłania powiadomień do użytkownika.
- Wysyłanie powiadomień push do użytkownika odbywa się poprzez Expo notification lub Firebase cloud messaging.
